# Livro Vivo — App (MVP)

Aplicativo (Expo + React Native) do **Livro Vivo**.

## Requisitos

- Node.js (LTS recomendado)
- npm
- API local rodando (`livro-vivo-api`)

## Instalação

```bash
npm install
```

## Rodar em desenvolvimento

```bash
npx expo start
```

Atalhos úteis no terminal do Expo:

- `w` abre no navegador (web)
- QR Code abre no Expo Go (celular)

## Integração com a API

Este app vai consumir endpoints do backend (livro-vivo-api).
Configuração de URL base/autenticação será adicionada nos próximos epics.
